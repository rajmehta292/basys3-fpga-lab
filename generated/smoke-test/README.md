# First Basys3 hardware lab

1. Open `basys3_hello.v` and change the `assign led = ...` line.
2. Use the included XDC to create a Vivado project for `xc7a35tcpg236-1`.
3. Synthesize, implement, generate a bitstream, and program the board.
4. Return to Mastery Lab and mark the checkpoint after you can explain every signal.

The board facts and pin names come from Digilent's Basys3 reference material.
